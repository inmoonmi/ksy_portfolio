# Sweet Toast — 김서영 UI/UX 포트폴리오

스크롤하면 토스트가 토스터에서 노릇하게 구워지고, 섹션마다 다른 잼이 발리고, 마지막에 과일 토핑이 쏟아지는 포트폴리오 웹페이지예요.
**의존성 0** — 빌드 없이 `index.html`을 더블클릭하면 바로 열려요. (Google Fonts만 인터넷 연결 시 적용)

```
sweet-toast/
├─ index.html          마크업 · SVG 스프라이트(소품/아이콘/거친 선 필터)
├─ css/style.css       디자인 토큰 · 레이아웃 · 모바일(≤1099px) 분기
├─ js/data.js          ★ 이름/경력/자격증/스킬/프로젝트(metrics 포함)/연락처/이력서 — 문구는 여기만 수정
├─ js/main.js          스크롤 엔진 · 잼/토핑 1회 재생 · 탭 필터 · 레시피 모달 · 폼
└─ assets/             toast, toaster-front/back, jam-*(색상별 잼), toast-toasted(구워진 토스트)
```

## 화면 구조 — 큰 스크롤 4구간 (긴 콘텐츠는 6화면)
휠/키보드(PageUp·PageDown·Space·방향키·Home·End)로 **한 화면씩** 부드럽게 넘어가요(`bindPaging`). 패널 사이 간격은 `--gap`(최소 320px, 히어로→about는 380px 이상)이라, 넘어가는 동안 토스트가 내려오는 모습이 보여요. 패널이 화면보다 길면 안쪽은 일반 스크롤, 모바일은 일반 스크롤이에요. 간격 조절: `style.css`의 `--gap`.
| 구간 | 패널 | 구성 (1~2열, 콘텐츠 가운데 정렬) | 잼(배경 장식) |
|---|---|---|---|
| title | 1 | 토스터 면에 한 줄 소개 + 취업·협업 가능 배지 | – |
| No.01 about | 2 | ① 프로필 + 성격 키워드(사례 한 줄) · 경력 · 자격증 ② 스킬 2카드 + 취미 메뉴판(사진 자리) | 딸기잼 (우→ / 좌→ 슬라이드 1회) |
| No.02 portfolio | 1~2 | 메뉴판 탭 + 2×2 카드 → `전체 보기` 누르면 2번째 화면(MENU 2)이 열림 | 마멀레이드 |
| No.03 contact | 1 | 좌 연락처 카드 · 가운데 토스트 접시(식탁) · 우 에어메일 폼 | 말차 + 체크 식탁보 |

## 모션 스펙 노트 (`js/main.js` 상단 `MOTION`)
- **토스트 = 움직이는 주체 (스크롤 연동).** 좌우 이동 · 말풍선 · 커피잔 없음, 표정은 contact 도착 때만 등장.
- ① 슬롯에서 **수직으로** 내려옴(스크롤의 0.5배 속도, 슬롯 라인 clip-path) + `toast.png → toast-toasted.png` 색 전환
- ② 완전히 나온 뒤(≈1090px) → contact까지 **일정한 속도로 계속 아래로** 이동, 배율 `1 → 0.62` (`endScale`), 도착 위치 하단 80% (`endBottom`)
- 콘텐츠가 우선: 토스트는 콘텐츠 뒤(z-index)에서 지나가고, 잼 블롭은 배경 장식
- 잼(딸기 · 마멀레이드)과 토핑 19개는 단계 진입 시 **1회 재생**, 위로 되돌리면 즉시 제거
- 모바일(≤1099px): 스냅 없음, 토스트는 상단 띠에 고정, 색 박스/잼은 아래→위, 레일은 하단 도크

## 좌측 레일
배경 박스 안에 `title / intro / works / contact` + 맨 아래 `TOP` 버튼(스크롤 후 활성). 현재 섹션 자동 강조(`aria-current`).

## 추가한 기능
스킵 링크 · OG/theme-color/JSON-LD/파비콘 · 레시피 모달 이전/다음 + 주소 해시(`#recipe-w1`) 딥링크 · 모달 열릴 때 배경 스크롤 잠금 · 임팩트(KPI) 숫자 · 이메일 복사 · 폼 검증 + 허니팟 · 이력서 PDF 버튼(`data.js → resume`) · 낮은 화면(노트북) 대응

## 빈티지 · 킷사텐 · 모리걸 요소
거친 연필 외곽선(SVG `feDisplacementMap`) · 종이 질감 + 필름 노이즈 깜빡임 · 마스킹 테이프 · 에어메일 봉투 · 우표(천공 가장자리) · 손그림 말풍선 · 압화 · 작은 꽃다발 · 크림소다 · 푸딩 · 나폴리탄 · 커피잔 · 킷사텐 램프(좌우로 살랑) · 체리/깅엄 체크

## 이미지/폰트 교체
- 프로필 사진: `data.js → profile.photo = 'assets/profile.jpg'`
- 프로젝트 썸네일: 각 work의 `img: 'assets/work01.jpg'` (비우면 손그림 목업이 표시돼요)
- 폰트: Jua · Gowun Dodum · Gaegu · Fredoka (Google Fonts). 오프라인이면 시스템 한글 폰트로 대체돼요.

## React로 옮길 때
`main.js`의 `measure() / frame() / setStage()`가 한 덩어리의 스크롤 엔진이라 그대로 `useEffect` 안에 넣고, `render*()`의 템플릿만 JSX로 바꾸면 돼요. GSAP을 쓴다면 `frame()`의 계산식을 ScrollTrigger `scrub`으로, `paintJam/dropToppings`를 timeline 1회 재생으로 대응시키면 돼요.

## 데이터 수정 (`js/data.js`)
- `profile.keywords` — 성격 키워드와 사례 한 줄 / `hobbies` — 취미(`photo`에 사진 경로) / `works[].problem·goal·steps·result·metrics·learned` — 문제 → 과정 → 결과 케이스 스터디
- 이름 · 연락처 · 회사 · 성과 수치는 전부 예시값이에요.


## 최신 변경 (Turn H)
- Contact: 메시지 폼 삭제, 이메일·전화·블로그 3박스만. contact가 문서의 끝(최대 스크롤 = contact 위치)이라 식탁 도착 후 추가 스크롤 반응 없음. 위로 올리면 잼 연출 재생.
- 프로필 카드: 사진 / 이름·한마디 / 성격 키워드 3등분 (사진은 `data.js`의 `profile.photo`).
- 히어로: 광택·나사·몰딩, 다이얼(스크롤에 따라 회전)·램프(점등), 명판(`hero.role`).
- 모바일: 토스터 슬롯에서 식빵이 나오는 연출 + 단계 간격 200px.
- 메뉴판: 하단 패딩 확대, 장식은 버튼과 겹치지 않는 위치로 이동.

## 결과물 목록 (모달)
